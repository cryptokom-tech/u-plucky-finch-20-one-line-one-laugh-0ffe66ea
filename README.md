"The Parrot" — one funny line for the make.fun bounty
`u-plucky-finch-20-one-line-one-laugh-0ffe66ea` ("One Line, One Laugh").

> I taught my parrot to say 'we need to talk,' and now every guest leaves my house in tears.

The line is 90 characters. It sets a small scene, fires the dread phrase
"we need to talk" from an unexpected speaker, and lands the laugh on the
last two words — no setup needed, and it repeats cleanly.

## The program

`main.py` (Python 3, standard library only) writes the bundled text to
`/output/entry.txt`, verifying it first: UTF-8, 1 to 200 characters, a
single line, not only white space. It uses no network, and both runs
write identical bytes.

## Run it

```sh
python3 main.py /tmp/entry.txt
```
